# Financial-Analysis-of-Tata-Steel
## 📊 Financial Analysis of Tata Steel Ltd (2013–2023)
This project is a financial modeling analysis of Tata Steel Ltd, focused on evaluating its financial health and performance over the last 10 years using key financial metrics. Built entirely in Microsoft Excel, the model helps analyze operational efficiency, profitability, and cost structure trends.

## 📌 Objective
To assess Tata Steel Ltd's financial stability by analyzing its historical performance using five core financial metrics.

## 📁 Project Features
10-year data analysis from company financial statements

Excel-based dashboards and charts for visualization

Ratio analysis to identify trends and performance shifts

Interpretation of results for financial health insights

## 🛠 Tools Used
Microsoft Excel (Charts, Formulas)

## 📈 Outcomes
The analysis helps determine how Tata Steel's key financial drivers evolved over the decade, providing insights into its profitability, cost efficiency, and investment potential.
